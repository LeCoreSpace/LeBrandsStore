---
name: Collection filtering direction
description: Collection-specific facets across every merchant theme
---
Every theme should offer collection filters based on the product types, variants
and descriptors of products actually in the selected collection, not the full
master catalogue.

**Why:** The user explicitly requested this across all themes.

**How to apply:** Preserve this requirement when adding themes or changing
collection browsing. Keep the existing catalogue classification and publication
boundaries rather than introducing theme-specific classification models.
