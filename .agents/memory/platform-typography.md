name: Platform typography
description: Consistent sans-serif defaults across platform pages and merchant storefronts.
---
Apply homepage font changes across the whole homepage, including the hero and
section headings, rather than changing only the currently visible hero slide.
Use the same clean font stack as Pricing and Compare, while retaining appropriate
homepage headline sizes and less tightly condensed letter spacing.

**Why:** The user said the hero font needed to change throughout the homepage,
immediately after requesting consistent Pricing and Compare typography. The
chosen implementation keeps the public platform typography consistent.

**How to apply:** Preserve carousel geometry, motion and responsive behavior when
updating typography.

The storyboard homepage uses the bundled Instrument Sans semibold for all
headings, with less cramped tracking and consistent hierarchy. Body text keeps
the platform's existing sans-serif stack.

**Why:** The user said the storyboard's heading font did not look professional
and requested refinement across the entire homepage before publication. Using
the existing self-hosted face avoids external font requests.

**How to apply:** Cover the primary heading, every section and card heading,
FAQ questions and footer headings. This homepage refinement does not authorise
changing merchant designs, operational screens or restoring the archived hero.

Visual hierarchy is intentional: “A store that tells your brand story and
sells.” and “Meet Ann.” are prominent headlines; the flagship-store sentence
is smaller supporting text, even though it remains the semantic H1.

**Why:** The user explicitly requested this size hierarchy.

Use clean sans-serif defaults across all platform pages and store pages, not
just the homepage. This extends the earlier homepage-only scope.

**Why:** The user pointed to the serif account/password page and explicitly
requested changing the font "in all pages including store pages".

**How to apply:** Cover shared account forms, dashboard/Ann, theme previews and
storefront commerce pages. Keep merchant-authored content and explicit inline
rich-text font selections intact; do not rewrite stored designs to change a
presentation default.
